# PaiPai Hostel – server-backed booking prototype

Install Python 3.11+, `pip install -r requirements.txt`. Set environment variables from `.env.example` (do NOT commit secrets). Start `gunicorn -w 1 -b 0.0.0.0:${PORT:-5000} server:app` on an HTTPS server with a **persistent DATA_DIR**. On localhost, use `python server.py` and `COOKIE_SECURE=0`.

Customer: `/` · Admin: `/admin` (ADMIN_PASSWORD defaults to none; configure `1978` on server as requested, and change it before public launch). The 4-digit booking code is a reference, NOT an authentication credential. Customer booking emails are sent after database save. Admin must manually verify bank transfer; slip presence does not verify payment. Emails are sent via SMTP; Gmail needs a dedicated app password or a suitable mail provider. If SMTP fails, the booking remains saved and the UI warns that email failed. Retrying email requires admin intervention. Protect persistent data and back it up; do not publish the slips directory. Limit traffic and add rate limiting, CSRF protection, monitoring, transactional email outbox, privacy/retention policy, and real deployment testing before production. Admin calendar price override is saved but customer prices currently use fixed type rates: integrate date-specific prices before public launch.
